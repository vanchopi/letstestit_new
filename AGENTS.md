# AGENTS.md

## UI Policy
- При реализации интерфейса и интерактивных элементов приоритетно использовать компоненты и возможности Vuetify.
- Нативные HTML/CSS/JS решения использовать только если в Vuetify нет подходящего инструмента или если это явно лучше для конкретной задачи.

## Code Style
- `Vuetify-first`: в UI-задачах сначала подбираем готовые компоненты, пропсы и утилиты Vuetify.
- Минимизируем кастомный CSS: добавляем собственные стили только когда это действительно необходимо для уникального внешнего вида или поведения.
